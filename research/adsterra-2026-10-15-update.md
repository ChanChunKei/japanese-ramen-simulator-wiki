# Adsterra 七单元与默认展示更新

日期：2026-10-15。按站主明确要求，Adsterra 默认加载，不再等待同意选择。站主同时确认先使用现有七份代码，每个页面每份代码只挂一处。GA4 继续遵循此前选择：同意后加载，拒绝或未选择不加载。

| 单元 | 首页 | 文章页 |
|---|---|---|
| 320×50 | 全站导航下方常驻 | 同左，取代旧手机底部广告 |
| Native | Hero 后 | 相关文章后 |
| 300×250 | 第二张最新文章卡后，<1024px | 第二个直接正文段落后，<1024px |
| 728×90 | 页面底部，≥1024px | 正文后广告组，≥1024px |
| 468×60 | 第二张最新文章卡后，≥1024px | 正文后广告组，≥640px |
| 160×300 | 不挂载 | 桌面目录下；≥1680px 移到右侧固定 |
| 160×600 | 不挂载 | ≥1680px 且高度 ≥768px 时左侧固定 |

固定广告保留平台原始尺寸，实际空间不足或 CSS 隐藏时不加载；Native 保留平台生成布局，iframe 高度随素材变化。首页最新文章改成纵向图文卡片，卡间只插一个对应设备的单元。同页不重复 300×250 或 728×90；增加同尺寸广告需要额外单元代码。

`AdsterraSlot` 统一加载与原生高度处理；`TopAnchorAd` 负责顶部占位和锚点留白，`SideRailAd` 管理正文两侧固定位置，`AdsterraSlotPair` 管理文章尾部广告组。正文手机广告在 iframe 加载前移动到第二段后，不逐篇修改 MDX。固定横幅使用独立 HTML / window，避免 `atOptions` 覆盖。Native 沿用本站已验证的独立 HTML 挂载。

公开配置写在 `wrangler.toml [vars]`，七个广告代码原文在 `public/ads/`。变量为空不渲染；更换单元需同时更新对应 HTML，不宣称目前只改 env 即可替换全部投放代码。没有添加 Popunder、Social Bar 或未经提供的 ads.txt seller ID。

隐私政策与统计横幅已同步说明：拒绝关闭的是 Google Analytics，Adsterra 仍自动展示。旧广告关闭偏好不再用于顶部广告。GSC 尚未提供验证值，本轮不改变其状态。

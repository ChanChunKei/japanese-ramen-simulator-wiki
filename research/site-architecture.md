# 固定站点信息架构

| 层级 | 组织方式 |
|---|---|
| 首页 | 游戏身份、当前 EA 状态、四个核心入口、真实内容更新、玩家问题、五类资料入口、FAQ、官方 Steam |
| Guides | 入门、控制/语言、配置、平台/发售/价格/Demo、存档、成就 |
| Cooking | 拉面菜单/组装（合并面条与配菜）、汤底与tare、饺子/饭碗、啤酒 |
| Restaurant | 订单票据、NPC单人、布局/图案、等级解锁、小偷/火灾、特殊顾客 |
| Multiplayer | 邀请开局、错误诊断、角色/语音/动线 |
| Updates | 一个官方版本跟踪页，维护原 URL |
| 辅助 | FAQ及五个法律/联系页面；标签和最近页服务浏览但不争抢核心搜索意图 |

URL 使用小写连字符和尾斜杠。英文根路径，不创建 /en/。页面优先用表格、步骤和条件判断，不设固定字数。首发矩阵在写作前冻结；不足证据的数值或条件删除，不用“待补充”文章公开凑数。

保留模板数据驱动导航、MDX路由、相关文章、面包屑、Pagefind、SEO与广告组件。新增通用视觉支持仅渲染locale数据。未填广告/统计/评论凭据保持关闭。

## 合并或取消

| 候选 | 处理 | 原因 |
|---|---|---|
| PS5 / Xbox / Switch / Mac / Linux 各独立页 | 合并平台页 | 同一发行平台意图，否定答案不足以单独造页 |
| Release countdown / 9月延期 / prelaunch | 合并平台页与版本历史 | 当前已发行，旧延期不是当前状态 |
| noodles / toppings / individual recipe pages | 合并拉面菜单页 | 没有逐食谱的当前比例/定时证据 |
| 单个食材百科 | 合并解锁表/汤底页 | 不复制竞品未核实属性 |
| 完整ROI/最佳价格/自动计算器 | 取消 | 数字缺少官方或实测依据 |
| 各boss五星最优配方 | 合并特殊顾客页 | boss名可证，目标配方和评分公式不可证 |
| casino赚钱技巧 / money exploit / mods / codes | 取消 | 真实机制细节或有效需求不足，不能编造 |
| random public lobbies / crossplay / offline | 在联机/平台/保存相关页解释边界 | 问题真实但肯定答案缺证据，不另造空页 |

首发20篇不代表所有游戏机制已被实测。对完整食谱、全部解锁树、人数上限冲突、离线依赖等边界在对应页明确说明。

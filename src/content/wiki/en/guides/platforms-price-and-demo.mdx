## Release date and current availability

Wild Dog released Japanese Ramen Simulator in Steam Early Access on **October 9, 2026**. The [release announcement](https://steamcommunity.com/ogg/4968640/announcements/detail/702155125711440122) gives 08:00 UTC, equivalent to 16:00 in mainland China and 17:00 in Japan.

An older September release slot was delayed during Steam review. That history is not the current release date. The live [Steam listing](https://store.steampowered.com/app/4968640/Japanese_Ramen_Simulator/?l=english) and official store metadata both mark the game as released.

| Platform question            | Verified answer as of October 10                                             |
| ---------------------------- | ---------------------------------------------------------------------------- |
| Windows PC                   | Available on Steam in Early Access.                                          |
| Native macOS                 | The official Steam API marks Mac support false.                              |
| Native Linux                 | The official Steam API marks Linux support false.                            |
| PS5, Xbox or Nintendo Switch | No release verified in the sources checked here.                             |
| Steam Deck                   | No Verified status or local compatibility test established in this research. |

The [official metadata endpoint](https://store.steampowered.com/api/appdetails?appids=4968640&l=english) is the source for native platform flags. A historical closed-test form accepting SteamOS applicants does not prove native Linux support or Steam Deck certification.

## Price and launch discount

The developer announced a US standard price of **$14.99**, with a **15% launch discount**. The US store snapshot checked for this guide showed **$12.74** and an October 23 discount end date.

Prices and discounts depend on region and time. Use the price shown to your own Steam account before buying. These US figures are a dated reference, not a promise that the same price applies worldwide or remains available after the launch promotion.

Before purchase, compare your machine with the [official system requirements](/guides/system-requirements/). We have not benchmarked the game or verified a target frame rate on every supported GPU.

## Is there a free demo?

The research confirmed historical closed beta tests and authorized creator previews. It did not verify a currently downloadable public free demo. A closed beta registration page is not a standing demo download.

Check the live Steam page for any new demo button. If the developer publishes a separate demo later, this page should be updated from that announcement rather than from an old preview title.

The [developer’s game website](https://wilddog.jp/japaneseramensimulator) is useful for identity and official links, but its older release wording must be checked against the newer Steam announcement.

## What Early Access means here

The game is in Early Access. This guide does not claim a guaranteed date for the full release.

The first numerical patch verified for this wiki is **v0.1.48.17626**. See the [patch tracker](/updates/patch-notes/) for the cooking, staff, controller and co-op changes documented on launch day. Historical beta footage may show different unlocks or interfaces.

## Single-player, multiplayer and offline questions

The store supports single-player and online co-op. NPC part-time staff are also described. To start with friends, use the [invite and co-op guide](/multiplayer/invite-friends/), which explains the conflict between official six-player and ten-player wording.

A [Steam player asked about offline operation](https://steamcommunity.com/app/4968640/discussions/0/590691913363919664/), but the checked thread did not establish an answer. Single-player support alone does not prove that every launch, save or feature works without internet. Offline behavior remains untested here.
